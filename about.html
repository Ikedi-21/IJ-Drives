The Project

What is IJDrives?

IJDrives is a Nigerian multi-modal transport marketplace — a single platform where travellers can search, compare and book buses, ferries, domestic flights and NRC trains across the country.

It's built as a portfolio project to showcase real-world frontend engineering: IndexedDB auth, a fake wallet with transaction history, a 4-step booking flow, live Leaflet maps with Stadia tile layers, and a fully responsive design system.

No real payments or bookings are made. All routes, fares and providers are fictional data created for the project. The ₦500 welcome bonus and wallet top-ups exist only in your browser's storage.

What's Built

Everything You'd Expect from a Real App

IJDrives implements the full user journey — from discovery to booking confirmation.

Auth System
Full sign-up and login with SHA-256 password hashing via Web Crypto API. Sessions stored in sessionStorage. ₦500 welcome bonus on sign-up.
Fake Wallet
Deposit funds, make bookings, and track every transaction. Full IndexedDB persistence — your balance survives browser refresh.
Live Maps
Leaflet.js + Stadia Maps tiles. Route preview with A/B markers and a dashed polyline. Dark and light map themes follow the app theme.
4-Step Booking
Route summary → passenger details → seat/class selection → wallet payment. Booking reference generated and saved to your history.
Smart Search
Search across all 68 routes by origin, destination, price and class. Cross-mode results page shows the cheapest options first.
Dark / Light Mode
Full two-theme design system with CSS variables. Your preference is saved to localStorage and applied instantly across all pages.
